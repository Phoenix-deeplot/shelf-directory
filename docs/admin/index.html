目录管理

连接你的 GitHub

这个页面没有后台：它用你的 GitHub 令牌，直接在你的浏览器里读写这个仓库的申请（issue）和触发更新。令牌不会发给任何别的地方。

怎么拿令牌
  1. GitHub → 右上角头像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。
  2. Repository access 选 Only select repositories，只选目录这个仓库。
  3. Permissions → Repository permissions：Issues: Read and write，Actions: Read and write（Metadata 自动是只读）。
  4. 设一个有效期（比如 90 天），生成后复制到上面。这个令牌只能操作这一个仓库。
