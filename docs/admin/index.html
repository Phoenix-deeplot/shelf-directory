目录管理

输入管理密码

密码在服务器上核对。GitHub 令牌放在服务器的环境变量里，不会出现在这个浏览器里；登录后拿到的只是一个会过期的通行证，只能做管理页上的几件事（看申请、通过 / 拒绝、删除已收录的、设置来源的状态、更新目录）。

用 GitHub 令牌登录

这个页面也可以不经过服务器：用你的 GitHub 令牌，直接在你的浏览器里读写这个仓库的申请（issue）和触发更新。令牌不会发给 GitHub 以外的任何地方。

怎么拿令牌
  1. GitHub → 右上角头像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。
  2. Repository access 选 Only select repositories，只选目录这个仓库。
  3. Permissions → Repository permissions：Issues: Read and write，Actions: Read and write，再加 Contents: Read-only（“来源”页要读登记的来源；Metadata 自动是只读）。
  4. 设一个有效期（比如 90 天），生成后复制到上面。这个令牌只能操作这一个仓库。
想改成输入密码就能管理？

  1. 在 GitHub 再生成一个令牌（同上：只选这个仓库，Issues 和 Actions 读写，再加 Contents: Read-only），不要和访客提交用的那个共用。
  2. 在 Vercel 的这个项目里加两个环境变量：ADMIN_GITHUB_TOKEN（上面的令牌）和 ADMIN_PASSWORD（你想用的密码，至少 12 个字符，最好是一句长长的话）。
  3. 重新部署一次（vercel --prod），刷新这个页面，就会出现密码框。

所有申请都在这里：GitHub 表单提交的、访客在网页上提交的网址、访客从个人书架公开的文章。通过 / 拒绝后由 GitHub Action 处理，不需要重新部署任何东西。
